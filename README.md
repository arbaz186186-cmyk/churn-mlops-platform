# Customer Churn Prediction - MLOps Platform

## Project Overview
This project aims to predict customer churn using Machine Learning and MLOps tools.

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- MLflow
- FastAPI
- Docker
- Git and GitHub
- Jenkins
- AWS
- Terraform
- Kubernetes
- Prometheus and Grafana

## Project Goals
- Build a Machine Learning model.
- Track experiments using MLflow.
- Deploy the model using FastAPI.
- Containerize the application using Docker.
- Automate CI/CD using Jenkins.
- Deploy infrastructure using Terraform and AWS.
- Manage applications using Kubernetes.
- Monitor the application using Prometheus and Grafana.

## Project Status
Currently in the initial setup phase.
